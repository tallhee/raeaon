# 래아온 비교노트

잠실래미안아이파크 입주자대표회의 업무를 다른 단지의 공고·규정과 비교해 보기 위한 공개 자료실입니다.

## 다루는 주제

| 주제 | 비교 항목 |
|---|---|
| 주차규정 | 공공개방시설 이용자 주차 제공 여부, 방문차량 요금, 세대 면적별 주차대수·요금 |
| 커뮤니티 운영규정 | 운영시간, 요금, 입장 횟수 |
| 커뮤니티 식당 | 업체 선정 방식, 운영시간, 요금 |
| 입대의·선관위 | 공고 모아보기 |

비교 단지는 두 그룹입니다. 하나는 서울에서 2020년 이후 입주한 단지, 다른 하나는 송파·강남·서초·강동구의 1,500세대 이상 대단지입니다. 조건은 `config/sources.json`에서 바꿀 수 있습니다.

## 어떻게 모으나 — 입대의 회의결과 (주력)

[서울시 공동주택마당](https://openapt.seoul.go.kr) 단지홈의 **정보공개 › 입주자대표회의** 게시판을 읽습니다. 로그인이나 API 키는 필요 없습니다.

1. 단지마다 게시판 목록을 훑어 구분·제목에 "결과·의결·회의록"이 들어간 글을 고릅니다. 개최 공고는 뺍니다.
2. 글의 첨부파일을 받아 글자를 뽑습니다.
   - 글자가 들어 있는 PDF는 그대로 읽습니다.
   - 스캔 PDF와 사진(JPG)은 글자 인식(Tesseract, 한국어)으로 읽습니다.
   - 한글(hwp/hwpx) 파일도 읽습니다.
3. "1. ○○의 건", "제5호 의안" 같은 안건 머리줄로 나눈 뒤, 주제어(주차·커뮤니티·식당·공공개방시설·관리업체·규정·예산)로 분류하고 찬반 결과를 뽑습니다.

수집은 매일 07:37과 19:37(KST)에 돌고, 처음에는 최근 400일치를 읽습니다. 한 번에 35분씩 읽고 남은 것은 다음 실행이 이어받습니다. 뽑은 전체 글자는 `docs/data/minutes_text/`에 남겨 두어 확인할 수 있습니다.

대상 단지와 주제어는 `config/openapt.json`에서 바꿉니다. 단지를 더하려면 단지홈 주소의 `aptCode` 값을 한 줄 추가하면 됩니다. 선거관리위원회 게시판은 `boards.03.enabled`를 `true`로 바꾸면 함께 읽습니다.

## K-apt 입찰공고 (참고, 수동)

예전에 만든 K-apt 입찰공고 수집(`scripts/collect.py`)은 자동 실행을 껐습니다. 필요할 때 Actions → "K-apt 입찰공고 수집 (수동)"에서 실행합니다.

## 구조

```
config/openapt.json            대상 단지, 주제어, 수집 범위
scripts/openapt.py             입대의 회의결과 수집·글자 인식·안건 분류
.github/workflows/minutes.yml  매일 2회 자동 수집
docs/                          GitHub Pages 사이트
  data/minutes.json            회의별 안건·주제·찬반 (사이트가 읽음)
  data/minutes_text/           첨부에서 뽑은 전체 글자
  data/rules.json              ← 원문 확인 후 직접 정리하는 규정 비교표
config/sources.json, scripts/collect.py, workflows/collect.yml   K-apt 입찰공고(참고)
```

## 손으로 채우는 부분

- **규정 비교표** (`docs/data/rules.json`): 공고문·관리규약·커뮤니티 운영세칙을 읽고 확인한 값만 적습니다. 모르는 칸은 `null`로 두고, 항목마다 `source`(원문 링크)와 `checked`(확인일)를 남깁니다.
- **단지 정보 보정** (`config/sources.json`의 `complex_overrides`): KG2B·아파트아이 같은 민간 전자입찰로 올라온 공고는 K-apt 단지코드가 없어 세대수·사용승인일을 자동으로 못 가져옵니다. 이런 단지는 여기에 적으면 비교 그룹 필터에 반영됩니다. 같은 단지명의 K-apt 공고가 한 번이라도 있으면 그 정보를 자동으로 빌려옵니다.

## 알려진 한계

- 첨부가 대부분 스캔 이미지여서 글자 인식에 의존합니다. 안건 제목과 찬반 문장은 잘 읽히지만, 표 안의 숫자나 시간은 틀리기 쉽습니다. 사이트의 **원문** 링크로 꼭 확인하세요.
- 안건 나누기와 주제 분류는 단어 규칙이라, 엉뚱한 주제가 붙거나 안건이 빠질 수 있습니다. `config/openapt.json`의 주제어를 고쳐 조정합니다.
- 공동주택마당 화면 구조가 바뀌면 수집이 실패하고, '수집 상태' 탭에 오류로 표시됩니다.
