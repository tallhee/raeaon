게시기간 : 2025.04.28.~2025.05.09.               녹번역e편한세상캐슬

입주자대표회의 결과 공고(1/2)
제3기 제10차[2025년 4월 25일(금) 19:30]

입주자대표회의 회의 결과를 아래와 같이 공고합니다.

| 참석 | 동별대표자 9명
| 일시 | 2025년 4월 25일 19:30~22:00
| 장소 | 입주자대표회의실(상가B동 2층, 106동 옆 E/L이용)
| 회의안건 |
제1호 의안 : 관리비부과명세서 보고의 건
  <의결사항> 원안과 같이 의결함(찬성 9명)
  <심의사항> 입주자대표회의 감사는 관리비부과명세서, 재무제표 등 회계 관련 서류가 적정하게
   작성되었음을 확인하였고, 생활지원센터장으로부터 관련 내용을 보고 받음.


제2호 의안 : 2025년 1/4분기 세입·세출 결산보고의 건
  <의결사항> 원안과 같이 의결함(찬성 9명)
  <심의사항> 생활지원센터장으로부터 2025년 1/4분기 세입·세출 집행실적을 보고받음
   유형자산감가상각비가 과소 계상되어 추후 추경 편성시 개선하기로 함


제3호 의안 : 장기수선충당금 예치의 건
  <의결사항> 다음과 같이 의결함(찬성 9명)
   1. 새마을금고(e푸른지점) 및 신협은행 정기예금 만기에 따라, 동일 은행에 각각 5,000
   만원씩 재예금 하기로 함
   2. 2024년 이익잉여금 처분액 65,225,530원 중 5,000만원은 녹번동 새마을금고에 예금
   하기로 함
   3. 이익잉여금 예금 후 잔액과 정기예금 만기이자는 보통예금 통장에 입금하기로 함


제4호 의안 : 장기수선충당금 사용의 건
  <의결사항> 다음과 같이 의결함(찬성 9명)


                                 - 이 어 서 -
입주자대표회의 결과 공고(2/2)
제3기 제10차[2025년 4월 25일(금) 19:30]




 1. 111동 승강기 인버터 및 메인보드 교체 : 입주민의 안전 및 이용 불편을 고려하여
 제조사인 현대엘리베이터에 의뢰하여 선 조치함. 교체비 8,400,000원(vat별도)은 장기
 수선계획의 긴급공사 대상으로 선 조치하고, 입주자대표회의에서 추인함
 2. 소방점검 지적사항 보수 : 소방점검 지적사항 중 방송용스피커 교체비 418,600원(vat
 별도)은 장기수선계획의 긴급공사 대상으로 선 조치하고, 입주자대표회의에서 추인함
 3. 배수로 트랜치 커버 구입 : 127동 재활용장 앞 트렌치 커버 파손 건은 안전사고 예방을
 위해 교체하기로 하고, 구입비 179,000원(vat포함)은 장기수선충당금으로 사용하기로 함
 트렌치 커버 보호를 위해 사각형 스톤볼라드를 설치하기로 하고 구입비는 수선유지비로
 사용하기로 함


제5호 의안 : 용역업체 재계약의 건
<의결사항> 다음과 같이 의결함(찬성 9명)
 1. 관리비 전산업무 : 업체명 : ㈜유니빌
               계약기간 : 25년 5월 20일 ~ 26년 5월 19일
               계약금액 : 650,000원/월
 2. 사무기기 임대 : 업체명 : 명성사무기기
             계약기간 : 25년 5월 8일 ~ 26년 5월 7일
             계약금액 : 363,000원/월
 3. 정화조 관리 : 업체명 : 해피론환경기술(주)
            계약기간 : 25년 6월 1일 ~ 26년 5월 31일
            계약금액 : 340,000원/월
 4. 정수기 렌탈 : 업체명 : UB컴퍼니
            계약기간 : 25년 6월 1일 ~ 30년 5월 31일
            계약금액 : 177,430원/월
