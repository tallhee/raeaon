n 제3안 :     커뮤니티 온수보일러 증설의 건 – 가결
Ÿ    썬코리아 경기특판을 통해 탱크용량 200리터+전기 30KW 증설 진행요망 → 탱크용량 증설
     4,950,000원(부가세별도)
Ÿ    전기증설 (약150만원)은 차기 입주자대표회의 안건으로 상정
Ÿ    비용처리: 주민공동시설적림금 사용
(표결결과 : 찬성6)
n 제4안 :     놀이터 보수공사의 건 – 가결
Ÿ    물놀이터 웅덩이를 모래로 채우는 부분 행위신고 대상여부 확인 필요
Ÿ    어린이들이 빨리 이용할 수 있도록 최대한 빠른 시간 내 보수 하기 위하여 관리사무소에서 자체 보수하
     고 하자 진단에 기여하는 부분이 미미하여 하자진단 전에 선 보수 진행 하기로 함
Ÿ    모래 사용여부는 관련규정 등 검토후 차기 재상정 (구청, 교육청등 법률적 문제도 검토 요망)
(표결결과 : 찬성6)
n 제5안 :     외벽 균열 보수 공사의 건 – 가결
Ÿ    외벽 균열보수는 법원하자감정 이후 27년 봄에 진행하는 것으로 의결함.
Ÿ    공사방법, 비용집행 등은 추후 논의
(표결결과 : 찬성6)
n 제6안 :     장기수선계획 수시조정 논의의 건 - 보류
Ÿ    10월 정기 입주자대표회의시 안건 재상정
(표결결과 : 보류6)

n 제7안 :     장기수선충당금 사용계획서 추인의 건 - 가결

Ÿ  공사개요 (부분수선)
