      제1호 의안 : 경관조명 설치의 건
       >의결사항 : - 단지 내 주요 동선 구간인 이대역 방향 주변이 어두워 추가 조명을 설치하기로 함.
                 - 수경시설을 포함하며, 장기수선계획의 예산 범위내에서 공사를 진행하기로 함.
                 - 업체 선정은 일반경쟁입찰, 최저가낙찰제, 전자입찰 방식으로 진행하기로 함.
                 - 전자입찰은 공동주택관리정보시스템(w w w.k - ap t.g o.k r ) 에 하기로 함.


     제2호 의안 : 조경관리의 건
       >의결사항 : - 단지 내 수목의 생육환경 개선을 위하여 지주목 정리 및 재설치, 병충해 수목 외과 수술을 진행하
                   기로 함.
                 - 업체 선정은 제한경쟁입찰, 적격심사제, 전자입찰 방식으로 진행하기로 하며, 입찰공고 세부 내
                   용은 첨부 공고문에 따르기로 함.


     제3호 의안 : 야외 탁자 및 파라솔 설치의 건
       >의결사항 : - 야외 탁자 및 파라솔 설치와 관련하여 현장조사를 추가로 실시한 후 추후 재논의하기로 함.


      제4호 의안 : 소방 작동점검에 따른 공사의 건
       >의결사항 : - 2026년 하반기 소방시설작동점검 결과 지적사항 중 자체 보수가 어려운 항목에 대하여 업체를 선
                   정하여 공사를 진행하기로 함.
                 - 견적서 제출업체 중 최저가 업체인 ㈜서울소방을 시공업체로 선정함.
                 - ㈜서울소방 견적금액(vat 별도) : 2,400 , 0 0 0 원
                 - 비교 견적금액(vat 별도) : 2,570 , 0 0 0 원


      제5호 의안 : 사우나 드라이기 구매의 건
       >의결사항 : - 커뮤니티 남·녀 사우나 이용자의 편의 증진 및 시설 개선을 위하여 노후 드라이기를 신규 제품
                   으로 교체하기로 함.
                 - ㈜무아스의 “슈퍼플라즈마 BLDC프로 드라이기” 14대(예비품 포함)를 구매하기로 함.
                 - 구매금액(VAT 포함 ) : 866, 6 0 0 원

  제6호 의안 : 입주민 행사의 건
    >의결사항 : - 입주민 화합과 분위기 쇄신을 위하여 10월 27일부터 28일까지 오전9시부터 오후11시까지
                단지 내 주민행사를 개최하기로 함.
              - 행사는 먹거리, 놀이시설 및 체험, 볼거리 등으로 구성하며, 아파트에서 부담하는 비용없이 계
                약을 체결하기로 의결함.


  제7호 의안 : 2단지 분수 운영시간의 건
    >의결사항 : - 2단지 분수대의 합리적인 운영시간을 결정하고 이용 만족도를 높이기 위하여 2단지 입주민을
                대상으로 설문조사를 실시하기로 함.
              - 설문 문항은 다음과 같이 구성하기로 함.
                1. 1안 : 4월1일부터 9월 30일 오전9시~ 오후7시까지 운영
                2. 2안 : 6월1일부터 8월 31일 오후1시~ 오후7까지 운영(현재 운영방식 유지)
              - 설문 참여자 중 과반수가 선택한 안을 최종 운영방안으로 결정하여 2027 년부터 시행하기로 함.


   제8호 의안 : 우수직원 포상의 건
    >의결사항 : - 우수사원 포상에 관한 사항은 추후 재논의하기로 함.


   제9호 의안 : 기타안건

                    단지내 게시판에 공지하기로 함.

         ② 공 용부 및 커 뮤 니 티관 련 추인 의 건
            >의결사항 : 공용부 및 커뮤니티 사용·지출 내역을 추인하기로 함.
