게시기간: 2026.1.9 ~ 2026.1.24.



(정기)입주자대표회의 결과 공고
마포그랑자이 제3기 제24차 정기 입주자대표회의 결과를 다음과 공고합니다.

| 참석 | 구성원 6명, 참석 6명
| 일시 | 2026년 1월 8일(목) 20시
| 장소 | 103동 멀티룸
| 안건 |
   제1호 의안 : 장기수선계획(정기검토조정)논의의 건

    >의결사항 : 장기수선충당금 부과금액은 차기 회의 시 재 논의하기로 하고 3년간 공사계획은 제안안을 승인

               의결함.

   제2호 의안 : 수영장, 사우나 리모델링의 건

    >의결사항 : 차기 회의 시 재 논의하기로 의결함.

   제3호 의안 : 복합기 임대업체 선정의 건

    >의결사항 : 복합기 임대기간 만료일이 도래되어 기존업체의 사업수행실적평가표 공고 후 이의 신청이 접수

               되지 않아 기존업체인 ㈜그린정보시스템과 1년간 재계약하기로 의결함.

               계약금액(VAT 별도 ): 2, 98 8, 0 0 0원

  제4호 의안 : 음식물종량기 유지보수업체 재계약의 건
    >의결사항 : 음식물종량기 유지보수업체의 계약기간 만료일이 도래되어 기존업체 사업수행실적평가표 공고 후

              이의 신청이 접수되지 않아 기존업체인 ㈜부민더블유엔피와 1년간 재계약하기로 의결함.

              계약금액(VAT 별도 ): 3, 64 8, 0 0 0원

   제5호 의안 : 안전관리계획서 승인의 건
    >의결사항 : 2026 년 안전관리계획서를 검토 후 승인 의결함.

   제6호 의안 : 25년 4/4분기 세입·세출 결산서 보고의 건
    >의결사항 : 25년 4/4분기 세입·세출 결산서는 25년 12월 사용 전기료등의 미고지로 인하여 차기 회의 시

               최종결산서를 보고받기로 의결함.

  제7호 의안 : 2단지 어린이 독서실 운영방식 논의의 건
    >의결사항 : 2단지 어린이 독서실을 교육 전문업체의 컨설팅을 받아 2월부터 운영하기로 의결함.

   제8호 의안 : 기타안건
     ① 공용부 및 커뮤니티 관련 추인의 건
       >의결사항 : 공용부 및 커뮤니티 비용 지출 내용을 추인 의결함.
