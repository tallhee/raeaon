게시기간: 2025.12.11~2025.12.25.



 (정기) 입주자대표회의 결과 공고
 마포그랑자이 제3기 23차 정기 입주자대표회의 결과를 다음과 같이 공고합니다.

                                          -다    음-

| 참석 | 구성원 6명 중, 참석 6명
| 일시 | 2025년 12월 10일(수) 19시
| 장소 | 103동 멀티룸
| 안건 |
   제1호 의안 : 주민 축제의 건
     >의결사항 : 주민화합 행사를 위하여 주민축제를 12월 24일과 25일 오전10시~ 오후1 0 시까 지 실시하기로
               하고 행사내용은 먹거리와 크리스마스 트리 포토존, 삐에로, 페이스페인팅, 캐리커쳐, 마술쇼를
               진행하기로 의결함.
               단, 축제 행사에 소요되는 비용은 없으며, 우천시 일정은 연기될 수 있음.

   제2호 의안 : 장기수선계획(정기검토조정)컨설팅업체 선정의 건
     >의결사항 : 장기수선계획 검토 조정업체로 견적서 제출 업체 중 최저가 업체인 장기수선기술원으로 선정하고
               장기수선사용계획서를 승인 의결함.
               견적금액(VAT 별도 ): 900, 0 0 0 원

   제3호 의안 : 2단지 독서실 안면인식기 설치업체 선정의 건
     >의결사항 : 2단지 어린이 독서실을 입주민 만 사용할 수 있도록 안면인식기를 설치하기로 하고 설치업체는
               아파트허브로 선정하며 운동시설적립금에서 집행하기로 의결함.
               견적금액(VAT 별도 ): 1, 60 0, 0 0 0원
   제4호 의안 : 2026년 소방시설 점검업체 선정의 건
     >의결사항 : 2026 년 2월에 실시 할 소방시설종합점검업체로 견적서 제출업체 중 최저가 업체인 서울소방으로
               선정 의결함.
               견적금액(VAT 별도 ): 3, 90 0, 0 0 0원
   제5호 의안 : 기타안건
     ① 하자소송 진행 논의의 건
        >의결사항 : 법무법인 좋은합동으로부터 감정보완신청서에 대한 설명 및 추후 진행되는 재판 일정에 대해
                  논의함.
      ② 공용부 및 커뮤니티 관련 추인의 건
        >의결사항 : 공용부 및 커뮤니티 비용 지출 내용을 추인 의결함.
