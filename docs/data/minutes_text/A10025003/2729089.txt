 제3호 의안 승강기유지관리 계약의 건
    >의결사항 : 오티스와 금액 협의 후 차기 회의 때 재 논의하기로 의결함.


  제4호 의안 기존사업자 재계약 및 입찰의 건
            (1. 경비업체 2. 미화업체 3. 재활용수거업체 4. 세차업체 5. 사우나청소업체)

    >의결사항 :

       1. 경비업체 : 차기 회의 때 재 논의하기로 하며 결정이 늦어질 경우 기존 계약업체인 에스원과 1개월 계약
                   연장하기로 의결함.

       2. 미화업체 : 마포구청에 자문을 받은 후 입찰공고하여 업체를 선정하기로 의결함,

                  선정방법: 제한경쟁/적격심사평가/전자 입찰 (k - a pt . go. kr ) /계약 기간 2년
                              자본금 10억이상으로 관계법령에 따른 허가 업체, 실적 5건 이상

      3. 재활용수거업체 : 사업수행평가서 작성 후 입주민 의견청취 결과 이의신청이 접수되지 않아 동일조건으로

                        1년 재계약하기로 의결함.
                        업체명 : ㈜삼성리사이클링,       계약금액(VAT 별도 ) : 8, 98 5, 6 0 0 원 /년

      4. 세차업체 : 사업수행평가서 작성 후 입주민 의견청취 결과 이의신청이 접수되지 않아 동일조건으로

                  2년 재계약하기로 의결함. 업체명 : 올베이스 계약금액(VAT 별도 ) : 9, 600, 0 0 0 / 2 년

                                         2023.5.30.
