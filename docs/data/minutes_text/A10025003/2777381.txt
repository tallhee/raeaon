  제1호 의안 : 2025년 서울시 공동주택 모범관리단지 지원사업 입찰의 건

   >의결사항 : 2025 년 서울시 공동주택모범관리단지 지원사업에 선정되어 현재 공실로되어있는 2단지 플라잉
             요가실을 어린이 교육장소로 변경하여 활성화 시키고자 인테리어 공사업체 선정방법을 다음과 같이
             의결함.
             입찰종류 : 일반경쟁입찰/ 최저가제/ 전자입찰(www. k - ap t . go. k r )
             참가자격 : 국토교통부고시 제2024 - 1 9 6 호 제26조 제1항에 해당되지 아니한 업체 중 실내건축업
                      면허, 등록 또는 신고업체


  제2호 의안 : 커뮤니티 운영규정의 건
   >의결사항 : 커뮤니티 이용자격 입주민 투표결과(4월1일 ~ 3 0일 ) 전체 세대수 1, 248 세대 중 497세대 투표참여
             (투표율 39. 82% ) 함.
             투표 참여 497세대 중 찬성 192세대, 반대 305세대로 찬성율이 38. 6 3%로 투표결과에 따라
             커뮤니티 운영규정 중 제5조 자격은 현행대로 유지하는 것으로 의결함.


 제3호 의안 : 수목 (재)하자의 건
  >의결사항 : 수목하자로 식재(24년 1 1 월) 한 수목 중 재하자가 발생한 수목에 대하여 하자청구를 하기로 하고
             수종 중 “선주목＂하자는 소나무로 대체하여 식재하기로 의결함.


  제4호 의안 : 201동 벽면 간판 설치업체 선정의 건
  >의결사항 : 201동 벽면 간판 설치업체 선정 입찰결과 3개의 유효한 업체 중 적격심사평가위원(7명) 의
             적격심사평가 결과 최고점수를 받은 ㈜세종에스씨 업체로 선정하고 공사금액은 장기수선충당금에서
             집행하기로 의결함.
             업체별 입찰금액(VAT 별도 ) 및 적격심사평가 점수

 제5호 의안 : 정화조 유지관리업체 선정의 건

   >의결사항 : 기존 사업자수행평가서 작성 후 입주민 의견청취 결과 이의 신청이 접수되지 않고 계약기간 중 관리가

            149, 0 0 0원 ( V AT 별도 )으로 2년 계약하기로 의결함.

            견적금액(VAT 별도 ) : 회계법인 청 1, 180 , 0 0 0 원,   A업체 1, 200 , 0 0 0 원
