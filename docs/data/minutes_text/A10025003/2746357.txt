 제1호 의안 : 커뮤니티 운영규정의 건
 >의결사항 : - 커뮤니티 운영규정 중 이용 자격을 현행 등본상 등록된 입주민만 이용에서 세대주의 가족관계증명서

             상 있는 분은 해당 세대의 커뮤니티 이용 인원이 3인인 경우 1명 추가 시 현행 커뮤니티 이용료

             3만원+α(3만원씩) 추가되며 최대 인원은 5인 이하로 만 등록 할 수 있다는(3인 이하는 기존대로 부과)

             규정을 입주자 등 투표를 통해 투표자의 과반수 찬성으로 결정하기로 의결함.
            - 입주자 등 투표는 4월 한달간 실시하고 상기의 조건으로 선거관리위원회에 입주민 찬반 투표 진행을

             요청하기로 의결함.


 제2호 의안 : 기존사업자 재계약 및 입찰의 건 (1. 경비업체                2. 전산업체)

  >의결사항 : 1. 경비업체

             마포구청에 자문을 받은 후 입찰공고하여 업체를 선정하기로 의결함.

             입찰방법: 제한경쟁/적격심사평가/전 자입찰 (k - a p t . go . kr ) 로 실시한다.

                     통합경비용역으로 입찰공고하며 자본금 10억이상, 관계법령에 따른 허가업체로 자본금

                     10억이상, 1000세 대 이상 공동주택 통합경비용역 5건이상 실적업체, 계약기간은 3년.

            2. 전산업체

             기존사업수행평가서 작성 후 입주민 의견청취 결과 이의신청이 접수되지 않고 계약기간 중 양호하여

             동일조건에 2년 재계약하기로 의결함.

             업체명: ㈜이지웹인프라        계약금액 (V A T 별 도 ) : 320, 0 0 0 원/ 월



 제3호 의안 : 장기수선계획서 수시조정의 건

  >의결사항 : 장기수선계획 검토결과 수시조정안을 승인 의결하며, 선거관리위원회에 동의 절차 진행을 요청하여

            입주자 과반수 동의 후 수시조정하기로 의결함.

제4호 의안 : 커뮤니티 안면인식기 추가 설치업체 선정의 건
  >의결사항 : 추후 재 논의하기로 의결함.



제5호 의안 : 저수조 청소업체 선정의 건
 >의결사항 : 2025년 상하반기 저수조 청소업체로 견적서 제출업체 중 최저가 업체인 플러스에코로 선정 의결함.

제6호 의안 : 배드민턴장 출입로의 건

 >의 결사항 : 배드 민턴장 출입로 보강공 사 업 체로 견 적서 제 출업체 중 최저 가 업 체인 오 컬트디 자인으로 선 정 의결 함.

제7호 의안 : 골프연습장 환기의 건

 >의결사항 : 골프연습장의 환기 시설로 통유리를 철거 한 후에 창문을 설치하기로 하고 업체는 견적서 제출 업체 중

           최저가 업체인 삼풍종합유리로 선정 의결함.

 >의결사항 : 타운보드 게시판을 원안대로 3대 이전 설치하기로 의결함.



제9호 의안 : 주민 축제 날짜 변경의 건
 >의결사항 : 제9차 입주자대표회의에서 4월 26일과 27일에 실시하기로 한 주민 축제 날짜를 5월 17일과 18일로

           변경하기로 의결함.
