  제1호 의안 : 경관조명 설치의 건
   >의결사항 : 입주민 통행이 가장 많은 110동 이대역 방향 출입구 주변이 어두워 추가로 조명 시안 등을 검토하고
             입주민 설문 조사를 실시하여 공사를 진행하기로 의결함.


  제2호 의안 : 야외 파라솔 설치의 건
   >의결사항 : 입주민 편의 증진을 위하여 휴식 공간인 야외 테이블 중 그늘이 필요한 곳에 파라솔 4개를 우선구입
             하여 설치하고 나머지는 차기 회의 시 재 논의하기로 의결함.
             (배드민턴장 옆 2, 201동 앞 정원 1, 2단지 놀이터 1)


  제3호 의안 : 조경관리 논의의 건
   >의결사항 : 단지 내 화단 교목의 원활한 생육을 위하여 지주목을 정리하고 전도될 위험성이 있는 수목에는 재설
             치 및 수목 생육상태를 개선하고자 화단의 토양 개량건으로 업체 견적을 받아본 후 차기 회의에서 재
             논의하기로 의결함.


  제4호 의안 : 피트니스센터 운동기구 구매의 건
   >의결사항 : 피트니스센터에 턱걸이, 웨이트 및 하체 근력운동을 위한 기구가 부족하여 턱걸이기구 1대, 웨이트
             기구1대, 스쿼트 기구 1대를 구입하기로 하며 내구성과 제품별 기능 사용 편의성을 감안하여 제품은
             뉴텍으로 선정 의결하며 커뮤니티 적립금에서 지출하기로 의결함.


  제5호 의안 : 201동 2호, 105동3호 옥상 방수업체 선정의 건
   >의결사항 : 최상층 세대 누수로 인하여 부분 방수공사를 주택관리업자 및 사업자 선정지침에 의거 수의계약하여
             공사를 진행하기로 하며 견적서 제출업체 중 최저가 업체인 수색대원건설㈜로 선정 의결함.
             견적금액( V A T 별 도 ): 수색대원건설㈜ 4,900 , 0 0 0 원, A업체 5,500, 0 0 0 원, B업체 7,00 0, 0 0 0 원


  제6호 의안 : 공동현관 입구 모기퇴치기 설치의 건
   >의결사항 : 많은 비용과 설치의 어려움이 있어 공동현관 모기퇴치기는 설치하지 않기로 의결함.
