               적격심사평가위원의 적격심사평가 결과 최고 점수를 받은 ㈜모두건설로 선정 의결함.

   제2호 의안 : 승강기 부품 교체의 건
     >의결사항 : 101동 1호기 승강기의 P CB(메인보드) 이상으로 교체하기로 의결하고 업체는 오티스엘리베이터로
                선정하며 공사금액은 장기수선충당금 사용계획서를 승인 의결함.
                견적금액(V AT 별도 ) : 4, 50 0, 0 0 0 원

   제3호 의안 : 커뮤니티 냉·난방용 심정펌프업체 선정의 건
     >의결사항 : 17차 입주자대표회의에서 선정한 업체(다산과)가 공사를 할 수없다고 하여 재선정하며 업체는
               견적서 제출업체 중 금액이 낮은 ㈜성광피이엠으로 선정 의결함.
               견적금액(VAT 별도 ) : 4, 70 0, 0 0 0원
   제4호 의안 : 기타안건
      ① 3/4분기 세입·세출 결산서 보고의 건
        >의결사항 : ¾분기 세입· 세출 결산서를 검토하였으며, 게시판에 공고하기로 의결함.
      ② 공용부 및 커뮤니티 관련 추인의 건
        >의결사항 : 공용부 및 커뮤니티 비용 지출 내용을 추인 의결함.
