제2기 11차 (2025년 2월)
정기 입주자대표회의 결과를 아래와 같이 공고합니다.

| 참 석 | 구성원 11명 중, 참석 10명

| 일 시 | 2025년 2월 19일 (수요일), 19:30 ~ 22:00

| 장 소 | 주민회의실

제1호 의안     : 25년도 1월분 관리비 부과내역서 추인 건
￭ 의결사항     : 부과내역서 원안대로 심의하고 관리비 (607,688,190원) 부과하기로 결정함.
             <찬성 10명, 반대0명>

제2호 의안     : 장기수선계획서 수정 건
￭ 의결사항     : 원안대로 장기수선계획 적립요율 구간별 단가를 수정하여 장기수선계획표에 반영하기로
             결정함. <찬성 10명, 반대0명>
             - 장기수선충당금 이입액을 적립구간 내에 분배 산입하여 단가 수정 필요
             - 장기수선계획서 구간별 적립요율표의 구간별 단가 수정
               l 1구간(23년~25년) : ㎡당 단가 61.721원 → 61.714원(부과금액동일)
               l 2구간(26년)     : ㎡당 단가 100원    → 90.002원으로 수정
               l 3구간(27년)     : ㎡당 단가 110원    → 105.017원으로 수정
               l 4구간(28년)     : ㎡당 단가 120원    → 119.988원으로 수정
               l 5구간 이후(29년~72년)는 ㎡당 단가가 조금씩 상승 수정

제3호 의안     : 24년도 결산(이익잉여금 처분) 건
￭ 의결사항     : 원안대로 2024년도 결산(이익잉여금처분) 하기로 결정함<찬성 10명 반대0명>

제4호 의안     : 주민공동시설(커뮤니티) 적립금 사용계획 건
￭ 의결사항     : 커뮤니티 적립금 사용 계획에 따라 적립금 사용하기로 결정함 <찬성 10명, 반대 0명>
