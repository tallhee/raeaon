(정기) 입주자대표회의 의결 공고
 제2기 6차 (2024년 11월)

정기 입주자대표회의 결과를 아래와 같이 공고합니다.
| 참 석 | 구성원 11명 중, 참석 10명

| 일 시 | 2024년 11월 20일 (수요일), 19:30 ~ 22:30

| 장 소 | 주민회의실

제1호 의안     : 24년도 10월분 관리비 부과내역서 심의 건
￭ 의결사항     : 관리비 부과 내역 심의 후 (579,565,270원) 부과하기로 결정함<찬성 10명, 반대0명>


제2호 의안     : 세대소독과 수목소독 입찰 분리 공고 건
￭ 의결사항     : 세대소독과 수목소독 입찰 시 분리하여 발주하기로 결정함<찬성 10명, 반대 0명>
             n 주택관리업자 및 사업자 선정 지침을 준수하여 절차 진행
             n 세대소독 업체 선정은 분리 입찰하고, 수목소독은 조경관리 용역 업체 선정시 포함


제3호 의안     : 보안 용역 업체 선정 건
￭ 의결사항     : 기존 사업자 재계약 절차 진행하여 업체 선정하기로 결정함<찬성 8명, 반대 2명>
             n 관리규약 제72조(기존사업자 재계약)에 근거하여 계약 기간이 만료되는 기존 사업자
               의 사업수행 평가표를 게시하여 입주민의 이의 신청을 받아 1/10 이하인 경우 입주자
               대표회의 의결로 재계약할 수 있음.
            n 관리주체는 기존 사업자 사업수행실적평가 결과를 게시판, 공동주택관리시스템에
              공고(10일 이상)하고 공고 기간 내 입주민 이의 신청 접수(생활지원센터) 1/10 이상
              접수 시 재계약 하지 않고 공개경쟁입찰 실시함.


제4호 의안     : 미화 용역 업체 선정 건
￭ 의결사항     : 기존 사업자와 재계약 하기로 결정함<찬성 10명, 반대 0명>
             n 관리규약 제72조(기존사업자의 재계약)에 따라 사업수행실적을 평가하여 평가 결과를
               10일 이상 게시하고 입주자등의 이의신청을 접수하여야 한다.
             n 이의신청 접수 기간 : 24. 10. 20 ~ 24. 11. 04(16일간)
             n 이의신청 접수 세대 : 0세대
             n 계약기간 : 25. 02. 01. ~ 27. 01. 31.(2년간)
             n 계약금액 : 금1,600,837,416원(2년/ 25년 최저시급적용)

             n 대관일 : 선거일 전일 및 선거일 총 2일 대관
             n 대관료 : 금500,000원(부가세 포함)
             n 지급액 : 부가세 제외한 금454,545원 지급

￭ 의결사항    : 원안대로 25년도 예산 및 사업계획 심의하여 의결함<찬성 10명, 반대 0명>
            n 3년차 하자 발췌 및 시공사 하자보수 관리 철저
            n 2025년도 세입예산 금7,779,402,617원
                     세출예산 금7,745,755,878원 승인

￭ 의결사항    : 롯데건설과 2년차 하자 관련하여 회의 개최하기로 결정함<찬성 10명, 반대 0명>
             n 롯데건설의 하자조사 보고서에 대한 2차 답변 공간기술단에 답변 요청함
             n 하자조사 업체(공간기술단)의 2차 답변을 받아 롯데건설과 3자 회의 개최

제8호 의안     : 미화 청소용 온수기 설치 건
￭ 의결사항    : 원안대로 미화 청소용 온수기를 설치하기로 결정함<찬성 10명, 반대 0명>
             n 겨울철 청소용품 세탁에 필요한 온수기 설치(마포걸레, 청소용포)
             n 지하에 설치된 미화 청소용 수전 5곳에 설치
             n 귀뚜라미 30리터 온수기 5개 설치(배관 작업 포함)
