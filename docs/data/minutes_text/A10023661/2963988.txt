1. 의결주문
6백만원 한도내에서 조경 수목 구입하는 안건에 대해 심의 의결하여 주시기 바랍니다.


2. 제안이유
아파트 단지 조경을 위해 수목을 구입하여 식재하고자 하는 바, 6백만원 한도내에서 구입하
여 식재하는 것을 제안하는 바입니다.


3. 주요 내용
1) 수목의 특성상 구입을 위해서는 직접 육안으로 확인하고 구매해야 하는 바, 금액 한도를
정하고 원예회사 방문하여 직접 구입하고자 하는 것임
2) 구입 및 식재 금액 : 총6백만원 이내
3) 구입품목 및 수량, 예상금액
  ① 미스김 라일락 30주 X 20,000 = 600,000원
  ② 백자작나무 6주 X 150,000 = 900,000원
  ③ 모란 30주 X 30,000 = 900,000원
  ④ 말채나무 10주 X 60,000 = 600,000원
  ⑤ 남천 30주 X 20,000 = 600,000원
  ⑥ 홍매화 10주 X 70,000 = 700,000원
  ⑦ 블루앤젤(3m) 4주 X 250,000 = 1,000,000원
  ⑧ 바크칩(40L) 20개 X 10,000 = 200,000원
  ⑨ 소계 : 총5,500,000원(품절, 단가 변동에 의해 달라질 수 있음)
4) 식재 위치 : 화단 빈 곳에 골고루 심는 것을 원칙으로 하되, 블루앤젤 4주는 경비실 옆 정
문 조형물 근처에 식재하고자 함
5) 포크레인 불러서 작업할 계획이며, 작업후 관리실 직원 점심 제공하고자 함
6) 정확한 비용은 별도 보고하고자 함
