2. 안건 상정 및 심의 의결

 1) 승강기 내부 에어컨 설치 행위허가 신청 동의 투표 결과 건

  ◎ 발언 내용

   - 발언자 : 4월 14일부터 4월 25일까지 승강기 내부 에어컨 설치 행위허가 신청
     동의 1,2차 전자(현장)투표 결과는 분양세대 1,744세대중 1,037세대가 동의하여
     전체 1,900세대 1/2 이상 54.6%의 동의를 받아 승강기 내부 에어컨 설치 행위
     허가 신청 동의 건은 요건을 충족하였습니다.
   - 발언자 : 임대세대는 왜 투표에 참가 안 하였나요?
   - 발언자 : 분양세대 만으로 1/2 이상 동의가 예상되었기에 절차상 간소화시켰습니
     다.

설치 행위허가 신청 동의 건은 요건을 충족함.




2) 장기수선계획서 수시조정 입주자 동의 투표 결과 건

◎ 발언 내용

 - 발언자 : 4월 14일부터 4월 25일까지 장기수선계획서 수시조정 입주자 동의
     1,2차 전자(현장)투표 결과는 분양세대 1,744세대중 873세대가 동의하여 전체
     1,900세대 과반수 이하인 873세대의 동의를 받아 장기수선계획서 수시조정
     입주자 동의 건은 요건을 충족하지 못하였습니다. SH임대 156세대의 동의 여부를
     기다리는 중이며, 비동의시 미투표 입주자에 대한 방문투표 실시할 계획입니다.
 - 발언자 : SH임대 156세대에 대한 동의 결과는 언제 나오나요?
 - 발언자 : 우리 아파트 투표결과를 보고 서울시에서 4,5일 후에 결정한다고 합니다.
 - 발언자 : 찬성할 것 같나요?
 - 발언자 : 아마도 분양세대 찬성이 50%를 넘었기 때문에 찬성할 것으로 예상됩니
     다.
 -
   - 발언자 : 임대세대 소유자는 SH공사가 아니지 않습니까?
   - 발언자 : 임대세대 소유자는 서울시이며 SH공사가 서울시의 의견을 대신 전달합
    니다.
