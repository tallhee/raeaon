2. 안건 상정 및 심의 의결

 1) 외부 회계감사인 선정의 건
   ◎ 발언 내용
    - 발언자 : 공동주택관리법에 따라 매년 1회 이상 외부 회계감사를 받아야 하며
      회계감사의 결과를 1개월 이내에 입주자대표회의에 보고하고 인터넷 홈페이지
      등에 공개하여야 하며 매년 회계년도 종료후 9개월 이내에 실시해야 합니다.
      최근 3개년간 감사를 실시했던 곳이며 가장 저렴한 견적을 제시한 바름회계법인
      을 외부회계감사인으로 수의계약 함을 제안합니다.
    - 발언자 : 작년 저희 아파트 구청 실태조사에서 약40~50건의 지적사항중에 그중
      예산회계에 관련해서 7건의 지적사항과 행정지도를 받은 사실을 있는데 바름회
      계법인의 역할은 무엇인가요?
    - 발언자 : 외부회계감사인은 재무상태표 등의 재무제표에 대해 감사를 하고 대표
      회의가 집행한 사실과 관련 근거자료를 확인합니다. 전산상의 자료를 바탕으로
  통장잔고 증명을 하며 대표회의 의결, 집행을 회계적으로 감사하여 구청에서 실시
  한 실태조사와는 차이가 있을 수 있습니다.


◎ 의결사항 : 2025년도 외부회계감사인으로 바름회계법인과 수의계약 함을 의결함.
  (전원찬성)




2) 소독(세대, 수목) 용역 사업자 선정의 건
 ◎ 발언 내용
  - 발언자 : 현재 저희 단지의 계약은 (주)와이브이시스템과 연간 2,640만원으로 계
   약이 되어 있는데 세대소독과 수목소독을 같이 한 업체에서 계약체결중인데, 한
   꺼번에 결합해서 한 계약은 강동구청 질의에서 좀 문제가 있다고 답변을 받아
   기존 사업자 사업수행실적평가를 통한 수의계약 보다는 세대와 수목소독을 분리
   하여 경쟁입찰하고자 합니다.
  - 발언자 : 업체에서 세대소독과 수목소독 견적을 나누어 제시하면 되지 않나요?
  - 발언자 : 나누어 금액 산정 가능하나 두개의 계약으로 나눠야 합니다.
  - 발언자 : 기존 사업자평가 점수가 90점이 넘는데 새로이 업체를 선정해야 하나
   요?
  - 발언자 : 세대소독과 수목소독을 분리계약 하려면 과거 사업자평가가 필요 없으
   며 구청의 권고사항을 따라야 할 것 같습니다.
  - 발언자 : 현재 이 안건은 공개경쟁입찰 선정을 의결 주문하였지만 회의자료에 포
   함된 내용에는 기존사업자의 수행실적이 우수하여 재계약을 진행하고자 하는 취
   지인지 결정에 어려움이 있으니 기존업체와 재계약하든지 공개경쟁입찰할지의
   여부를 대표님들께서 결정하면 될 것 같습니다.



◎ 의결사항 : 소독(세대, 수목) 용역사업자를 세대와 수목으로 구분하여 공개경쟁
  입찰(제한경쟁입찰, 최저가 낙찰제)하기로 함.(전원찬성)
   제한사항 : 자본금 5억, 최근 5년간 공동주택 1,500세대이상 사업실적 5곳 이상

3) 세차 업체 선정의 건

◎ 의결사항 : 단지내 세차 업체 선정은 관리규약 제72조(기존 사업자의 재계약)에

4) 커뮤니티 시설 운영 관련 건
 ◎ 발언 내용
  - 발언자 : 매년 7월에 커뮤니티 시설 운영에 대한 수입,지출을 분석함에 프로그램
   별 손익은 25년 기준으로 월평균 각각 헬스장은 –439만원, 골프연습장은 +78만
   원, 사우나는 -1,265만원, 카페는 –785만원, 독서실은 –369만원으로, 현재 공용
   이용료를 각 세대당 1만원씩 정액부과하고 있습니다. 적자해소방안에 대해서는
   오늘 커뮤니티 운용업체에서 발표하겠습니다.
  - 발언자 : 사우나 적자를 보전하기 위해 추가 세대원 1인 헬스 추가와 사우나 15회
   추가되는 월 15,000원의 통합플러스권을 제시합니다.
  - 발언자 : 사우나외에 카페나 로봇카페의 적자에 대해서도 적극적인 해결 방법을
   마련하면 좋겠습니다.
  - 발언자 : 공용시설이면서도 수익사업인데 이용요금을 수익자부담으로 합리적인
   요금 산정이 쟁점사항입니다.
  - 발언자 : 이전에 요금을 한 번 올린 적이 있는데 배경을 설명해 주시면 좋겠습니다.
  - 발언자 : 24년도 당시에 사우나가 본격적으로 시작되고 카페 재료비 비중 과다
   로 세대당 5천원에서 1만원으로 인상하였습니다.
  - 발언자 : 신축아파트의 커뮤니티 시설이 문제가 되는데 입주민의 편의를 위해 만

 들어진 시설에서 요금을 외부보다 많이 받을 수는 없습니다. 사우나의 경우 최근
 에 수도 및 전기 사업자의 공급 단가가 많이 상승하였습니다. 커뮤니티는 공용시
 설이므로 매달 이용료를 필요한 만큼 증액해서 공동으로 부담하는 방법과 주변
 아파트의 사례로 손실비용을 매달 정산하여 부과하는 방법도 있습니다.
- 발언자 : 한달에 1만원을 유지한다면 계속 적자 상태가 지속될 것이고 시설 수
 리에 들어가는 비용은 관리비로 계속 충당됩니다.
- 발언자 : 커뮤니티는 아파트의 가치를 상승시킬 수 있고, 공동시설이므로 이용을
하지 않는다고 해서 요금을 부담하지 않는 것도 논리적으로 맞지 않을 것 같고,
적자 폭을 어떤 방법으로 부담할지 고민해야 할 것 같습니다.
- 발언자 : 제안하신 월 15,000원 통합플러스권의 경우 사우나 이용횟수가 늘어나
 면 사우나 수도료 등 운영비가 같이 상승할 경우 적자폭을 기대만큼 감소시킬
 수 있나요?
- 발언자 : 사우나 운용시에 주된 비용은 급탕비인데 샤워를 많이 한다고 해서 그
 비용이 크게 늘어나진 않고 증가되어도 최대 월 1백만원 미만으로 예상됩니다.
- 발언자 : 제안하신 상품의 경우 헬스인원이 많아 질 수 있을텐데 현재 저녁에 보
 면 이용인원이 많은데 더 수용가능한가요?
- 발언자 : 제안한 회원권 판매시, 이용률은 약 10% 정도로서 트래픽은 크게 변
 하지 않을 것 같습니다.
- 발언자 : 커뮤니티를 운영한 지 약 7년이 지난 관계로 일정 부분 충당금을 적립
 하여 향후의 노후 시설교체를 준비해야 될 것 같습니다.
- 발언자 : 사우나 운영시간을 확대하면 어떨지요?
- 발언자 : 사우나 시설 운영중 발생하는 소음 민원과 운영시간에 따른 인건비 상
 승분을 감안하면 우리 아파트 상황에선 어렵다고 생각합니다.
- 발언자 : 현재, 커뮤니티 중 사우나와 카페를 제외하고는 수익은 있습니다. 카페
 의 경우 원부자재 비용이 높으며 사실 팔수록 손해인 구조입니다.
- 발언자 : 그럼 사우나 이외에 카페운영 적자도 감축해야 할 것 같습니다.
- 발언자 : 타 단지의 공동 이용료도 고려하면 좋겠습니다.
- 발언자 : 이번달 새로운 프로그램인 줌바댄스와 유아 놀이프로그램인 아카아카
 페페가 있습니다.
- 발언자 : 세대수가 비슷한 타 단지의 공동이용료도 고려해야 하겠습니다.
- 발언자 : 공동이용료 금액과 커뮤니티에서 제안해 주신 상품과 카페 솔베뉴 음료
 의 가격 조정 등에 대해 고민을 더 해서 차기에 다시 논의하도록 하겠습니다.
- 발언자 : 지난 5월에 기타 동호회가 연회장을 무단 사용하였고, 적치물 치워달라
는 요청과 함께 무단사용을 금지하였습니다. 혹시 이후에도 무단 사용이 있는 건
