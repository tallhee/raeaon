   관리주체가 산하 의견서에 맞게 관련 내용을 적극적으로 확인하고 공유하는 역할
   을 해주시면 좋겠습니다.

     적 단가의 변동이 왜 심한지 확인후 이번 로프 계약을 진행해 주십시오.
    - 발언자 : 승강기안전관리공단의 제재 사항은 없는지요?
    - 발언자 : 조건부 합격인 경우 2개월내 조치하면 제재사항은 없습니다.


  5) 기타
   ◎ 발언 내용
    - 발언자 : 기타동호회 대관장소인 주민회의실은 너무 좁아 연회장을 대관해 주시
     면 어떨까요?
    - 발언자 : 기타동호회의 악보대 등의 적치물이 연회장에 있습니다. 한마당잔치시점
     에 인포데스크에서 잘 모르고 열어 준 것 같습니다.
    - 발언자 : 저희가 연회장 대관 규정이 있나요?
    - 발언자 : 현재 연회장 대관 규정은 없습니다. 7월에 커뮤니티 시설 이용 관련 건
     에서 논의 가능합니다.
   - 발언자 : 논의될때까지는 무단사용을 금지하고, 적치물을 치워주시기를 요청 부탁
     드립니다.
