      공고번호                                     2025. 4.   3.부터
                                        게시기간
대표 제2025 - 04 - 02호                            2025. 4. 16.까지




      제목 : 제3기 입주자대표회의 4월 임시회의
                결과 안내

  우리 아파트 2025년 4월 임시 입주자대표회의 개최 결과를 아래와 같이 알려드리
 오니 참고하시기 바랍니다.


                            - 아   래 -

  1. 일시 : 2025. 4. 2. (수) 오후 7시
  2. 장소 : 입주자대표회의실 (커뮤니티 라운지)
  3. 회의 안건 및 심의 결정 사항

    가. 감사 및 이사 선출 - 선거관리위원장 주재
       : 선거관리위원장의 주재로 공동주택관리법 시행령 제12조2항에 의거,
         구성원 과반수의 동의로 선출함.
       ▷ 감사 선출 : 이현우 대표
       ▷ 총무이사 선출 : 김성범 대표
       ▷ 기술이사 선출 : 서동용 대표

    나. 조경 관리용역업체 선정 건
       ▷ 조경 유지관리 용역업체 선정하기로 함.
       ▷ 선정방법 : 제한경쟁입찰, 적격심사제
       ▷ 제한사항 : 자본금 5억, 실적 1000세대 이상 5개단지 외

    다. 2025년 가정의 달 페스티벌 개최 건
       ▷ 2025년 가정의 달 페스티벌을 개최하기로 함.
       ▷ 개최 일시 : 2025년 5월 17일
       ▷ 예산 : 400만원
       ▷ 프로그램은 전년도 프로그램에서 일부 수정하기로 함.
  라. 2025년 2월 관리비 부과내역
     ▷ 관리주체로부터 관리비 부과내역을 보고받고 이를 승인함.

  마. 기타
     ▷ 이익잉여금 처분 시행 보고 : 장기수선충당금을 예치함.
       - 장기수선충당금 처분사항을 보고 받고 승인함.

   ▷ 공동체 활성화 단체 실적보고(경로당)
    : 공동체 활성화 단체(경로당) 실적보고를 받고 승인함.

   ▷ 공동체 활성화 단체 실적보고(주차 보안관)
    : 공동체 활성화 단체(주차 보안관)의 실적보고를 받고 승인함.

   ▷ 월간 업무보고
    : 관리주체의 월간 업무보고를 받음.
