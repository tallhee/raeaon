  2. 장소 : 입주자대표회의실 (커뮤니티 라운지)
  3. 회의 안건 및 심의 결정 사항

   가. 주택 위수탁관리업체 선정 건
    ▷ 주택관리업자 선정 입찰조건을 제안하고 입주자등의 동의를 요청하였으나,
        과반수 동의 미달로 재투표하기로 한다. 재투표 실시기간과 재투표율이 60%
        이하인 경우의 투표기간 연장등을 선거관리위원회에 요청키로 함.
      - 입찰 제한사항 : 3월 대표회의 의결사항 원안 유지

     ▷ 견적을 비교하여 최저가와 수의계약하기로 함.
      - 계약업체 : 한서회계법인
       - 계약기간 : 2026.06.01. ~ 2027.05.31.
       - 계약금액 : 연 660,000원(VAT별도)


   다. 기계성능점검업체 선정 건
      ▷ 기계성능점검을 위하여 견적을 비교하여 최저가와 수의계약하기로 함.
       - 계약업체 : 에이스산업기술(주)
       - 계약기간 : 2026.05.01. ~ 2027.04.30.
       - 계약금액 : 연 1,900,000원(VAT별도)


    라. 단지 내 대형화분 꽃잔디 식재 건
      ▷ 단지 내 환경 개선을 위하여 꽃잔디를 구매하기로 함.
       - 납품업체 : 동심원 조경
       - 품목 및 수량 : 꽃잔디 90판
       - 금액 : 720,000원(VAT별도)
