      공고번호                                2025. 04. 23.부터
                                   게시기간
대표 제2025 - 04 - 04호                       2025. 05. 06.까지




      제목 : 제3기 입주자대표회의 4월 정기회의
                결과 안내
  우리 아파트 2025년 4월 정기 입주자대표회의 개최 결과를 아래와 같이 알려드리
 오니 참고하시기 바랍니다.
                      - 아 래 -

  1. 일시 : 2025. 4. 22. (화) 오후 7시
  2. 장소 : 입주자대표회의실 (커뮤니티 라운지)
  3. 회의 안건 및 심의 결정 사항
     가. 승강기유지관리업체 선정 건
       ▷ 기존 승강기유지관리업체인 현대엘리베이터(주)의 사업수행실적을 평
         가하고 재계약하기로 의결함.
       ▷ 계약금액 : 70,560,000원
       ▷ 계약기간 : 2025.06.01.~2027.05.31.(2년)
     나. 소독용역업체 선정 건
       ▷ 기존 소독용역업체인 (주)태은환경의 사업수행실적을 평가하고 재계약
         하기로 의결함.
       ▷ 계약금액 : 10,008,000원(수목소독 제외)
       ▷ 계약기간 : 2025.05.01.~2027.04.30.(2년)
     다. 음식물 쓰레기 계량장비 유지보수 계약 건
       ▷ 기존 음식물 쓰레기 계량장비 유지보수업체인 일월정밀(주)의 사업수행실적
         을 평가하고 재계약하기로 의결함.
       ▷ 계약기간 : 2025.06.01.~2027.05.31.(2년)
       ▷ 계약금액 : 6,758,400원
     라. 세무주치의 계약 건
       ▷ 기존 세무주치의 업체인 한서회계법인의 사업수행실적을 평가하고 재계약하
         기로 의결함.
       ▷ 계약기간 : 2025.06.01.~2026.05.31.(1년)
       ▷ 계약금액 : 660,000원
     마. 커뮤니티 통합관리 시스템 계약 건
       ▷ 기존 커뮤니티 통합관리 시스템업체인 ㈜트러스테이의 사업수행실적을 평가
        하고 재계약하기로 의결함.
       ▷ 계약기간 : 2025.06.01.~2027.05.31.(2년)
       ▷ 계약금액 : 2,400,000원
     바. 게시판 광고업체 선정 건
       ▷ 게시판 광고업체의 기존 계약금액 대비 45% 인하된 가격으로 제안하였기에
        공개경쟁입찰로 업체를 선정하기로 함.
    ▷ 입찰방법 및 낙찰방법 : 일반경쟁, 최고가 낙찰
 사. 기계설비 성능점검업체 선정 건
    ▷ 기계설비 성능점검업체 선정방법은 500만원이하로 견적을 비교하여 최저가
      업체로 선정하기로 함.
    ▷ 계약업체 : 에이스산업기술(주)
    ▷ 계약기간 : 2025.05.01. ~ 2026.04.30.(1년)
    ▷ 계약금액 : 1,900,000원
 아. 주민공동시설 2분기 프로그램 운영계획(안) 보고 건
    ▷ 현행과 같이 프로그램 운영하기로 함.
 자. 층간소음 관리위원회 구성 건
    ▷ 관리규약 제94조에 의거, 층간소음관리위원회를 구성하기로 의결함.
    ▷구성원 : 관리소장, 동별대표자1, 선관위원회1, 경로당 회원1, 주차보안관등
     중 1인으로 구성하기로 함.
 차. 2025년 3월 관리비 부과내역
    ▷ 관리주체로부터 관리비 부과내역을 보고받고 이를 원안대로 승인함.
 카. 기타
    ▷ 조경 유지관리용역업체 선정 및 계약체결
      - 조경 유지관리용역업체를 적격심사제로 선정하고 계약 체결을 보고 받고
       승인함.
      - 업체명 : ㈜대신엘앤씨조경
      - 계약금액 : 37,770,000원
      - 계약기간 : 2025.05.01.~2026.04.30.(1년)
    ▷ 공동체 활성화단체 실적보고 (경로당 및 주차보안관)
      - 경로당 및 주차보안관의 실적을 보고받고 이를 승인함.
    ▷ 입주자대표회의실 현판 설치 건
      - 커뮤니티 라운지 입구에 현판을 설치하기로 함.
      - 현판 규격 : 가로 80Cm * 세로 60Cm
      - 재질 : 스텐절곡
      - 시안 : 2번
    ▷ 홍보부스 운영 건
      - 단지내 홍보부스 광고를 허용하기로 함.
      - 부스 설치 위치 : 어린이집 옆
      - 부스 운영 수익 : 1,000,000원(한달)
